# 📋 入力パラメータ

すべての実行方法は以下の統一パラメータをサポートします：

| 入力パラメータ | 必須 | デフォルト値 | 説明 |
|-----------------|----------|---------------|-------------|
| `apikey` | はい | - | LLMサービスのAPIキー |
| `base_url` | いいえ | DeepSeek | LLMサービスのエンドポイントURL |
| `model` | いいえ | DeepSeek v3 | LLMサービスのモデル名/識別子 |
| `RESERVED_WORD` | はい | - | 翻訳から除外する予約語/フレーズ |
| `DOCS_FOLDER` | はい | - | ドキュメントフォルダへのパス |
| `CONFIG_FILE` | はい | - | プロジェクトのi18n設定の設定ファイル |
| `FILE_LIST` | いいえ | - | 処理する特定のファイルリスト（オプション） |
| `workspace` | はい | - | コードリポジトリのワークスペースへのパス |
| `target_language` | いいえ | `'zh'` | 翻訳のターゲット言語コード（例：`'zh'`は中国語） |
| `max_files` | いいえ | `'20'` | 処理する最大ファイル数 |
| `dryRun` | いいえ | false | ドライラン モードを有効化（変更を加えずに実行をシミュレート） |
| `usecache` | いいえ | true | LLMリクエストのキャッシュを有効化 |
| `disclaimers` | いいえ | true | 翻訳の最後に免責事項を表示 |
