# 📋 معلمات الإدخال

تدعم جميع طرق التنفيذ المعلمات الموحدة التالية:

| معلمة الإدخال | مطلوب | القيمة الافتراضية | الوصف |
|-----------------|----------|---------------|-------------|
| `apikey` | نعم | - | مفتاح API لخدمة LLM |
| `base_url` | لا | DeepSeek | عنوان URL لنقطة النهاية لخدمة LLM |
| `model` | لا | DeepSeek v3 | اسم/معرف النموذج لخدمة LLM |
| `RESERVED_WORD` | نعم | - | مصطلحات/عبارات محجوزة لاستبعادها من الترجمة |
| `DOCS_FOLDER` | نعم | - | المسار إلى مجلد الوثائق الخاص بك |
| `CONFIG_FILE` | نعم | - | ملف التكوين لإعدادات i18n للمشروع |
| `FILE_LIST` | لا | - | قائمة محددة من الملفات للمعالجة (اختياري) |
| `workspace` | نعم | - | المسار إلى مساحة عمل مستودع الكود الخاص بك |
| `target_language` | لا | `'zh'` | رمز اللغة الهدف للترجمة (مثل `'zh'` للصينية) |
| `max_files` | لا | `'20'` | الحد الأقصى لعدد الملفات للمعالجة |
| `dryRun` | لا | false | تمكين وضع التجربة الجافة (يحاكي التنفيذ دون إجراء تغييرات) |
| `usecache` | لا | true | تمكين التخزين المؤقت لطلب LLM |
| `disclaimers` | لا | true | عرض إخلاء المسؤولية في نهاية الترجمة |
