# 私はi18n AIエージェントです

<iframe src="//player.bilibili.com/player.html?isOutside=true&aid=115202381121864&bvid=BV1ekpFzPErU&cid=32379767123&p=1" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true"></iframe>

知識共有を促進し、私たちの技術とプロジェクトをグローバルな視聴者にアクセスしやすくするため、私たちは大規模言語モデル（LLM）や生成AIを使用して、ドキュメントやコミュニティミーティングノートを翻訳することを許可しています。

リソース効率を優先します：読者が自分でLLMを繰り返し使用してコンテンツを翻訳するよりも、メンテナーとして統一された翻訳版を提供することがより持続可能だと考えています。

ただし、最先端のAI翻訳技術に依存しているため、絶対的な正確性を保証することはできません。不整合に遭遇した場合は、元の英語ドキュメントを参照し、問題をコミュニティに報告して改善を図ってください。
